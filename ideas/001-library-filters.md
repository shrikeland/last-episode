# Фильтры по типу, жанру и оценке в библиотеке

## Проблема
В библиотеке можно отфильтровать только по статусу и поискать по названию. Чтобы найти «все аниме, которые я оценил выше восьми» или «всё в жанре триллер», приходится глазами перебирать сетку. При этом сама библиотека уже умеет это фильтровать — просто некому попросить.

## Что видит пользователь
В `FilterBar` рядом с существующими селектами появляются:
- **Тип** — Все / Фильм / Мультфильм / Сериал / Аниме
- **Жанр** — список жанров, реально встречающихся в библиотеке (не весь справочник TMDB)
- **Оценка** — Все / 8+ / 6+ / без оценки

Фильтры складываются друг с другом и с существующими, живут в URL, переживают перезагрузку. Когда активен хоть один — под панелью строка «Найдено N» и кнопка сбросить.

## Почему это дёшево / дорого
Серверная часть написана целиком. `lib/supabase/media.ts:28-42` уже обрабатывает `type`, `genre`, `minRating`, `maxRating` — все четыре фильтра из `MediaFilters` (`types/index.ts:117`).

Наверх это не выведено. `app/(app)/library/page.tsx:29-33` собирает `filters` только из `search`, `status` и `genre`, причём `genre` берётся из URL, но задать его через UI нельзя — селектора нет. `params.type` не читается вообще, хотя в `SearchParams` объявлен.

То есть половина фичи уже оплачена и лежит мёртвым грузом. Нужны три селекта в `FilterBar` и пара строк в `page.tsx`.

Список жанров для селекта собирается из уже загруженных `items` — отдельного запроса не нужно.

## Скоуп
- `components/library/FilterBar.tsx` — три новых `Select`, пропс со списком жанров
- `app/(app)/library/page.tsx` — прокинуть `type` и `minRating` в `filters`, посчитать список жанров, поправить `hasFilters`
- Миграция БД: не нужна
- `'use client'`: `FilterBar` уже клиентский
- Внешние вызовы: нет

## Чего НЕ делаем
Без фильтра по году и по длительности. Без сохранения пресетов фильтров. Без мультивыбора жанров — один жанр за раз, как сейчас работает `.contains`. Без верхней границы оценки в UI, хотя `maxRating` поддержан: «8+» покрывает реальный сценарий, а два ползунка усложняют панель.

## Открытые вопросы
- Панель уже занимает всю ширину на десктопе. Четыре селекта в ряд на мобильном не влезут — сворачивать во «Фильтры» с выпадашкой или переносить строкой?
