## Goal
Добавить в библиотеку сортировки «Недавно добавленные» (`created_at`) и «Недавно обновлённые» (`updated_at`), чтобы свежий тайтл не тонул среди старых. Идея — [ideas/003](../ideas/003-sort-recently-added.md).

## Approach
- `SortField` расширяется на `'created_at' | 'updated_at'` — обе колонки уже есть в `media_items` и в типе `MediaItem`
- `getMediaItems` не трогаем: `.order(field)` принимает имя колонки как есть
- В селект `FilterBar` — два пункта наверх списка. Значения `created_at_desc` / `updated_at_desc` разбираются существующим `lastIndexOf('_')` корректно
- Дефолт меняется синхронно в двух местах: `page.tsx` и значение селекта в `FilterBar`
- Попутно — белый список полей сортировки в `page.tsx`: сейчас `params.sort` из URL уходит в `.order()` без проверки, и `?sort=foo` роняет страницу ошибкой Postgres. Раз строку всё равно трогаем, закрываем за один раз
- Без миграции, без новых компонентов, без внешних вызовов

## Risks / open questions
- **Секции по типу ограничивают эффект.** Без фильтров библиотека сгруппирована по типу (`LibrarySections.tsx:6`), сортировка работает внутри секции. Новое аниме будет первым в «Аниме», но ниже всех фильмов. Сквозной «что я недавно закинул» — вне скоупа; если окажется, что этого мало, это отдельная идея (например, «Недавно добавленные» как плоский список без секций)
- **Смена дефолта затронет друзей.** Рекомендация — менять: «что я недавно добавил» спрашивают чаще, чем «что новее по году», а старое поведение остаётся в селекте одним кликом. Если владелец против — пропустить два пункта чеклиста про дефолт, остальное не меняется
- **«Недавно обновлённые» не видят отметок серий.** `updated_at` двигается только от статуса, оценки и заметки (`updateMediaItem`, `lib/supabase/media.ts:104`). Для «что я недавно смотрел» есть идеи 002 и 004 — не пытаться подменить их этой сортировкой
- Публичный профиль (`app/actions/users.ts:71`), статистика и AI-рекомендации тоже зовут `getMediaItems`, но без аргумента сортировки — они остаются на дефолте `release_year` из `lib/supabase/media.ts:45`. Этот дефолт не трогаем, иначе поменяется порядок в чужих профилях
